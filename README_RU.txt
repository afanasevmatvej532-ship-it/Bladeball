ВАЖНО: онлайн не заработает, пока не подключён Firebase. Это не готовый подписанный APK, а исходный Android-проект для сборки APK.

ПОДРОБНАЯ НАСТРОЙКА FIREBASE: смотри FIREBASE_SETUP_RU.txt. Краткая последовательность ниже.

НАСТРОЙКА FIREBASE (один раз):
1. Открой https://console.firebase.google.com/ и создай проект.
2. В проекте добавь Web-приложение (значок </>) и скопируй конфигурацию.
3. Открой файл app/src/main/assets/index.html.
4. Найди FIREBASE_CONFIG и замени значения:
   apiKey — на apiKey из Firebase;
   authDomain — на authDomain;
   databaseURL — на databaseURL Realtime Database;
   projectId — на projectId;
   appId — на appId.
5. В Firebase открой Authentication → Sign-in method и включи Anonymous.
6. Создай Realtime Database. В разделе Rules для тестового прототипа можно поставить:
   {
     "rules": {
       "beatballRooms": {
         "$room": {
           ".read": "auth != null",
           ".write": "auth != null"
         }
       }
     }
   }
   Это упрощённые правила для теста: любой вошедший анонимно пользователь сможет менять данные комнат. Не используй их для платной игры или хранения личных данных; для публичного релиза нужны более строгие правила и серверная проверка.
7. Сохрани Rules и подожди несколько секунд.

СБОРКА APK:
1. Установи Android Studio на компьютер.
2. Распакуй архив и открой папку BeatballAndroid как проект.
3. Дождись Gradle Sync.
4. Выбери Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в app/build/outputs/apk/debug/.

ПРОВЕРКА ОНЛАЙНА:
1. Установи APK на два Android-устройства.
2. На первом выбери 1 на 1, 3 на 3 или 5 на 5 и нажми «Создать комнату».
3. Передай шестизначный код второму игроку.
4. На втором устройстве введи код и нажми «Войти».
5. Хост нажимает «Начать онлайн-матч».

В текущей версии хост рассчитывает физику матча и отправляет снимки состояния остальным игрокам. После каждого гола состав игроков повторно синхронизируется, поэтому боты снова уступают места подключённым игрокам. Локально проверены синтаксис JavaScript, запуск лобби, физика 1×1, 3×3 и 5×5 и отрисовка. Реальное соединение двух устройств не проверялось: для него необходимы Firebase-конфигурация и настроенная Realtime Database. Для коммерческого релиза стоит перенести авторитетную физику на сервер и добавить строгие правила доступа.

СБОРКА ЧЕРЕЗ GITHUB С ТЕЛЕФОНА (если нет компьютера):
1. Создай новый пустой репозиторий GitHub.
2. Загрузи в него содержимое папки BeatballAndroid, сохранив структуру папок (включая .github/workflows).
3. Открой вкладку Actions и разреши запуск workflows, если GitHub попросит.
4. Запусти workflow “Build Beatball APK” через Run workflow или сделай push в main.
5. После успешной сборки открой завершённый запуск workflow и скачай artifact “Beatball-debug-apk”.
6. Распакуй artifact ZIP на телефоне — внутри будет app-debug.apk.

Перед сборкой обязательно вставь Firebase-конфигурацию в app/src/main/assets/index.html и загрузи изменённый файл в GitHub.
