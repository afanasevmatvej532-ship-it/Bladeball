НАСТРОЙКА FIREBASE ДЛЯ БИТБОЛ ОНЛАЙН

Это обязательная настройка один раз. Без неё локальная игра работает, но комнаты через интернет не создаются.

1. Открой https://console.firebase.google.com/ и войди в свой Google-аккаунт.
2. Нажми «Создать проект». Назови его, например, beatball-online.
3. Внутри проекта нажми значок Web </> и зарегистрируй приложение. Имя можно указать Beatball Android.
4. Firebase покажет объект firebaseConfig. Перенеси значения apiKey, authDomain, databaseURL, projectId и appId в файл:
   app/src/main/assets/index.html
   Найди FIREBASE_CONFIG в начале скрипта и замени все строки-заглушки.
   databaseURL нужно копировать из Realtime Database, не составлять вручную.
5. В Firebase открой Build → Authentication → Get started → Sign-in method и включи Anonymous.
6. Открой Build → Realtime Database → Create Database. Выбери ближайший регион.
7. В Realtime Database открой вкладку Rules и вставь содержимое файла database.rules.json, затем нажми Publish.
8. Сохрани изменения index.html. Не публикуй apiKey в сообщениях и не присылай пароль Google. Firebase web apiKey сам по себе не является паролем, но конфигурацию лучше передавать только для настройки проекта.
9. Собери APK через GitHub Actions по инструкции в README_RU.txt.

ВАЖНО О БЕЗОПАСНОСТИ:
Правила в database.rules.json предназначены только для тестового прототипа: любой анонимно вошедший пользователь сможет читать и менять данные комнат. Не используй эти правила для публичного релиза, покупок или личных данных. Для релиза нужны серверная проверка ходов, ограничение прав хоста и проверка участников комнаты.

ПРОВЕРКА:
Установи APK на два телефона. На первом создай комнату, на втором введи её шестизначный код. Хост нажимает «Начать онлайн-матч». Свободные позиции занимают боты; при подключении игрока бот на его позиции заменяется игроком.

Если Firebase показывает ошибку, скопируй сюда только текст ошибки. Не присылай пароль Google, резервные коды или приватные ключи.
